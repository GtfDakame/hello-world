## 1. Видение продукта

### 1.1 Миссия
Вернуть цифровому общению естественность, тишину и уважение к вниманию пользователя.

### 1.2 УТП
«Мессенджер, который не шумит. Передает только важное. Работает быстрее мысли.»

### 1.3 Целевая аудитория
- Возраст: 18–45 лет
- Профиль: Ценят время, приватность, эстетику
- Боль: Устали от «информационного шума» традиционных мессенджеров

---

## 2. Принципы дизайна

### 2.1 Когнитивная легкость
- Интерфейс воспринимается за <0.8 сек
- Избегать визуального шума, скрытых меню, вложенных настроек
- Не более 5 вариантов выбора на экране (Закон Хика)

### 2.2 Эргономика
- Зоны касания ≥44×44pt (iOS), 48×48dp (Android)
- Критичные действия в пределах большого пальца (Закон Фиттса)

### 2.3 Эмоциональный дизайн
- **Висцеральный:** Чистая типографика, мягкие тени, «дышащий» ритм анимаций
- **Поведенческий:** Отклик <50мс, предсказуемые жесты, offline-индикаторы
- **Рефлексивный:** Прозрачность шифрования, контроль над уведомлениями

### 2.4 Без Dark Patterns
- Запрещено навязывать подписки
- Запрещено скрывать отмену действий
- Запрещено манипулировать вниманием
- Все согласия явные, обратимые, с контекстом

## 4. Технические требования

### 4.1 Производительность
| Метрика | Target | Измерение |
|---------|--------|-----------|
| Время до первого сообщения | <8 сек | От установки до отправки |
| Задержка отправки (95p) | <100мс | End-to-end latency |
| Время запуска (cold) | <2 сек | Launch to interactive |
| FPS при скролле | ≥58 | 60fps target |
| Crash-free sessions | ≥99.9% | Analytics tracking |

### 4.2 Безопасность
- Zero-knowledge архитектура по умолчанию
- X25519 + AES-256-GCM / ChaCha20-Poly1305
- Forward secrecy, double ratchet для E2EE
- Keychain (iOS), Keystore (Android), Secure Enclave
- Независимый аудит до GA

### 4.3 Доступность
- WCAG 2.2 AA минимум
- VoiceOver/TalkBack поддержка
- Высокая контрастность режим
- Уменьшение анимаций опция
- Скринридер-метки для всех элементов

## 5. Пользовательские сценарии

### 5.1 Onboarding (Zero Onboarding)
```
Шаг 1: Установка приложения
Шаг 2: Ввод номера телефона/email (3 сек)
Шаг 3: Верификация OTP (автоматическое чтение SMS)
Шаг 4: Импорт контактов (опционально, явный consent)
Шаг 5: Первое сообщение (<8 сек от начала)
```

### 5.2 Отправка сообщения
```
1. Открытие чата (список чатов → тап)
2. Ввод текста (поле ввода всегда видимо)
3. Отправка (кнопка или swipe)
4. Подтверждение доставки (галочки)
```

### 5.3 Жесты
- **Свайп вправо:** Ответить
- **Свайп влево:** Удалить/Переслать
- **Long-press:** Контекстное меню
- **Pull-down:** Поиск

## 7. Ограничения и зависимости

### 7.1 Hard Constraints
1. Никаких dark patterns
2. Нативный UI для каждой платформы
3. No plaintext ключей без согласия
4. Анимации ≤350мс
5. Открытый крипто-протокол

### 7.2 Зависимости
- Push notification сервисы (APNs, FCM)
- SMS провайдеры для OTP
- CDN для медиа-контента
- Сервисы для независимого аудита
